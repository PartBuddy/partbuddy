# CAD operation icons from Zoo Design Studio

Supersedes [ADR 0014](0014-cad-icon-glyphs.md).

## Context and Problem Statement

Tabler has no recognisable glyphs for CAD operations: the app showed a Bézier curve for fillet, a
ruler for chamfer and a layer stack for shell. ADR 0014 planned to draw a dozen own glyphs on the
Tabler grid. The product owner decided on 2026-11-04 to use free, professional icon sets instead of
drawing own ones, and to use the terms common in CAD software.

## Considered Options

* Zoo Design Studio's icons (KittyCAD/modeling-app, MIT) for CAD operations, Tabler for the rest
* icon-rs (MIT or Apache-2.0)
* Tabler only, with the closest general glyphs

## Decision Outcome

Chosen option: **Zoo Design Studio for CAD operations, Tabler for the rest** (product owner, after
a side-by-side comparison of 20 operations on 2026-11-05). Zoo's set is maintained by a company,
used in a released CAD program and covers every operation PartBuddy shows: sketch, extrude, revolve,
sweep, loft, fillet, chamfer, shell, hole, linear and circular pattern, mirror, split, helix,
boolean operations, plane and dimension.

* `tools/icons/build-zoo-icons.mjs` takes the path data of the listed icons from Zoo's
  `src/components/CustomIcon.tsx` at one pinned commit and writes `ui/zooIcons.ts` with Zoo's
  licence beside it (`ui/zooIcons.LICENSE`). Only filled paths are taken over; the script stops on
  anything else.
* `CadIcon` renders them like a Tabler icon (`className` for size and colour, `currentColor`,
  decorative unless labelled). Its view box crops Zoo's 20 px grid to the 16 px drawing area, so a
  glyph fills the same space as a Tabler icon of the same size.
* Used in the timeline, the selection actions, the structure panel and for the dimension tool.
  Primitives (box, cylinder), bodies, states and general UI stay Tabler. Shell uses Zoo's `hollow`
  glyph: at 14 px its `shell` glyph is hard to tell from `hole`.
* Terms in English and German follow common CAD software; the list is in the design system.

### Consequences

* Good: recognisable CAD glyphs without own drawing work; one pinned source, regenerated by a script.
* Good: MIT is compatible with GPL-3.0-or-later; the licence ships with the icons.
* Bad: two icon styles side by side, filled glyphs on a 20 px grid beside Tabler's 2 px lines. They
  appear in separate places (CAD operations versus general UI), which keeps the mix readable.
* Bad: Zoo may rename or redraw icons; a newer commit is taken over deliberately and checked by eye.

## Pros and Cons of the Options

### icon-rs

* Bad: one author, a month old, covers only a few operations, shaded colour style; several names
  echo another vendor's toolbar.

### Tabler only

* Good: one consistent style.
* Bad: fillet, chamfer, shell and patterns stay makeshift symbols.
